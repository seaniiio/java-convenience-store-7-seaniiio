# java-convenience-store-precourse
## 💻 기능 구현 목록

### 입력

- [ ] 주문 목록을 입력받는다.
- [ ] 프로모션 적용이 가능한 상품에 대해 고객이 해당 수량보다 적게 가져온 경우, 그 수량만큼 추가 여부를 입력받는다.
- [ ] 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제할지 여부를 입력받는다.
- [ ] 멤버십 할인 적용 여부를 입력 받는다.
- [ ] 추가 구매 여부를 입력 받는다.

### 출력
- [ ] 환영 인사와 함께 상품명, 가격, 프로모션 이름, 재고를 안내한다. 만약 재고가 0개라면 재고 없음을 출력한다.
- [ ] 구매 상품 내역, 증정 상품 내역, 금액 정보를 출력한다.

### 주요 기능
- [x] products.md, promotions.md 파일을 불러와서 내용을 저장한다.
- [ ] 주문 목록을 검증 후 저장한다.
  - [ ] 재고가 충분한지 확인한다.
- [ ] 주문에 대해 프로모션 적용 여부를 확인한다.
  - [ ] 오늘 날짜를 기반으로 프로모션이 적용되는지 확인한다.
  - [ ] 프로모션이 적용되는 경우 
    - [ ] 프로모션 재고를 먼저 차감한다.
    - [ ] 프로모션 재고가 부족한 경우 일반 재고를 차감한다.
    - [ ] 프로모션 재고가 부족한 경우를 확인한다.
    - [ ] 프로모션 조건만큼 구매하지 않았는지 확인한다.
- [ ] 멤버십 할인을 적용하는 경우
  - [ ] 프로모션 미적용 금액의 30%를 할인한다.
  - [ ] 최대 8,000원을 적용한다.
- [ ] 영수증 출력에 필요한 값을 계산한다.

### 예외 상황
- [ ] 구매할 상품과 수량 형식이 올바르지 않은 경우
- [ ] 존재하지 않는 상품을 입력한 경우
- [ ] 구매 수량이 재고 수량을 초과한 경우
- [ ] 의사를 묻는 질문에 Y/N 외의 입력이 주어진 경우
